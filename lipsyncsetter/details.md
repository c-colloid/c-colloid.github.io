# 詳細設定

## 自動で割り当てられる内容

アバターを割り当てると、アバターディスクリプターから次の内容が自動で入力されます。

- **Face Mesh**: アバターディスクリプターのリップシンク設定（Viseme用メッシュ）
- **LipSync**: アバターディスクリプターで設定されたViseme用のBlendShape
- **FX Layer**: アバターディスクリプターのFXレイヤー（従来版）

::: info
アバターディスクリプターのリップシンクが **Viseme Blend Shape** 以外の設定のときは、これらは自動入力されません。手動で設定してください。
:::

## 設定項目

### Face Mesh

リップシンクに使うBlendShapeを持つメッシュです。ほかのメッシュを割り当てると、そのメッシュのBlendShapeでアニメーションを作成できます。

### LipSync

各Visemeに割り当てるBlendShapeを選ぶ一覧です。項目は次の16個です。

```
sil, PP, FF, TH, DD, kk, CH, SS, nn, RR, aa, E, ih, oh, ou, Disable
```

ドロップダウンの選択肢は次のとおりです。

| 選択肢 | 意味 |
|-------|------|
| -none- | BlendShapeを割り当てない（アニメーションキーを登録しません） |
| disable | 無効扱い（アニメーションキーを登録しません） |
| （BlendShape名） | Face Meshが持つBlendShape |

::: tip
未設定（-none-）の項目はウィンドウ上でハイライトされます。
:::

### FX Layer（従来版）

リップシンクを書き込むアニメーターコントローラーです。デフォルトではアバターに割り当てられているFXレイヤーに上書きします。

### New FX Layer（従来版）

フォルダアイコンのボタンで作成する新しいFXレイヤーです。作成すると、既存のFXレイヤーの内容が統合された新しいアニメーターコントローラーが使われ、アバターディスクリプターのFXレイヤーにも設定されます。

## 生成されるもの

| 内容 | 説明 |
|-----|------|
| アニメーションクリップ | Visemeごとに作成されます（従来版は保存先に、ファイル名は `v.` で始まります） |
| リップシンクのレイヤー | FXレイヤーに追加されます（従来版では、同名のレイヤーがある場合は置き換えられます） |
| パラメータ | リップシンクに必要なパラメータがFXレイヤーに追加されます |

::: info
従来版では、アバターディスクリプターの **Customize** が有効になり、FXレイヤーがカスタム扱いに設定されます。
:::

## VoiceBoost

Expression MenuにVoiceBoost用のコントロールを追加する機能です（v1.5.0〜）。

### 従来版

ウィンドウの **VoiceBoost Menu** に追加先のExpression Menuを設定してから **Create** を押します。

### 非破壊版

1. Hierarchy上で右クリックし、**Add LSSVoiceBoost** を選択
2. 追加されたオブジェクトのInspectorで **Install Target Menu** に追加先のExpression Menuを設定
3. アバターをアップロード

### 追加される内容

| 追加先 | 内容 |
|-------|------|
| Expression Menu | `VoiceBoost` という名前のRadial Puppet |
| Expression Parameters | `VoiceBoost`（Float、初期値 0、Saved、Synced） |

すでに同名のものがある場合は追加されません。

## 非破壊版の動作

- LipSyncSetterのオブジェクトは、アバターのビルド時（アップロード時）に処理されます
- 処理後、ビルド用のコピーからLipSyncSetterとLSSVoiceBoostのオブジェクトは取り除かれます
- 元のアバターのFXレイヤーは書き換えられません
- NDMF（Non-Destructive Modular Framework）に対応しています

## 保存先（従来版）

アニメーションやFXレイヤーの保存場所は、作成時にフォルダ選択ダイアログで指定します。

::: tip
アニメーションファイル名はステート名ベースです。同じBlendShapeを設定した場合でも別のアニメーションになるため、後から修正しやすくなります。
:::

## よくある質問

### Q: 非破壊版と従来版のどちらを使えばいいですか？

アバターを書き換えたくない場合は非破壊版を使ってください。FXレイヤーに直接書き込みたい場合や、NDMFを使わない場合は従来版を使います。

### Q: Face Meshの選択肢にBlendShapeが出ません

Face Meshに、BlendShapeを持つSkinned Mesh Rendererが設定されているか確認してください。

### Q: リップシンクが動きません

LipSyncの各項目が `-none-` のままになっていないか確認してください。未設定の項目はハイライト表示されます。
