# 使い方

[導入方法](./getting-started)を済ませたら、非破壊版か従来版のどちらかで設定します。

| バージョン | 特徴 |
|-----------|------|
| 非破壊版 | アバターのアセットを書き換えず、アップロード時に自動で適用されます。通常はこちらがおすすめです |
| 従来版 | エディタウィンドウでアニメーションを作成し、FXレイヤーへ書き込みます |

## 非破壊版

1. Hierarchy上で設定したいアバターを右クリックし、**Add LipSyncSetter** を選択
2. 追加されたオブジェクトのInspectorで、**Face Mesh** に顔のメッシュを設定
3. LipSyncの各項目が目的のBlendShapeになっていることを確認
4. 違っている項目は、ドロップダウンから目的のBlendShapeを選択
5. そのままアバターをアップロード

::: info
Face Meshを設定すると、アバターディスクリプターのリップシンク設定をもとにLipSyncの各項目が自動で割り当てられます。
:::

::: warning
LipSyncSetterのオブジェクトはアバターの子として置いてください。親にあるアバターディスクリプターを参照します。
:::

## 従来版

1. ツールバーの **Tools** → **LipSyncSetter** を選択
2. 開いたウィンドウの **Avatar** 欄にアバターをドラッグ&ドロップ
3. **Face Mesh**、**FX Layer** が自動で入力されることを確認
4. LipSyncの各項目が目的のBlendShapeになっていることを確認し、違っていればドロップダウンから変更
5. **Create** ボタンを押す
6. アニメーションの保存場所を選択
7. 「リップシンクの作成が終了しました!」と表示されたら完了

### ウィンドウの各部

| 項目 | 説明 |
|-----|------|
| Avatar | 対象のアバター |
| Face Mesh | リップシンクに使うBlendShapeを持つメッシュ |
| LipSync | 各Visemeに割り当てるBlendShapeの一覧 |
| FX Layer | 書き込み先のアニメーターコントローラー |
| フォルダアイコンのボタン | 新規FXレイヤーを作成 |
| New FX Layer | 作成した新規FXレイヤー（作成後に表示） |
| VoiceBoost Menu | VoiceBoostを追加するExpression Menu |
| リロードボタン | ウィンドウの設定をリセット |
| Create | リップシンクを作成 |

各項目の詳しい内容は [詳細設定](./details) を参照してください。

### 新しいFXレイヤーに統合する

既存のFXレイヤーを上書きしたくない場合は、フォルダアイコンのボタンから新規FXレイヤーを作成してから **Create** を押します。

1. FX Layerの横にあるフォルダアイコンのボタンを押す
2. FXレイヤーの保存場所を選択
3. **New FX Layer** に新しいアニメーターコントローラーが表示される
4. **Create** を押してアニメーションの保存場所を選択

### 警告が出たとき

| 状況 | 表示 |
|-----|------|
| Face Meshが未設定 | 「FaceMeshが設定されていません」のダイアログが出て、該当の欄が強調されます |
| FX Layerが未設定 | 「FXLayerにアニメーターコントローラーが割り当てられていません」のダイアログが出ます。FX Layerを割り当てるか、新規FXレイヤーを作成してください |

::: tip
BlendShapeが未設定（-none-）の項目は、ウィンドウ上でハイライト表示されます。
:::
