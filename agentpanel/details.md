# 詳細設定

## Unity操作ツール（UapOps）

パネルは内蔵のMCPサーバ（ローカルループバック限定・トークン認証）を通じて、エージェントにUnityエディタを直接操作させられます。設定の **Unity連携** → **Unity操作(UapOps)** で「Unity操作(UapOps)を有効化」をオンにし、使うモジュールを選びます。

依頼は普通の言葉で構いません（例: 「選択中のオブジェクトの子にPointLightを追加して強度を3にして」）。エージェントが対応する `uap_*` ツールを選び、許可カードを経て実行します。

### Coreで使えるモジュール

| モジュール | できること |
|-----|------|
| **コア** | シーンオブジェクトの作成・検索・inspect、コンポーネント追加、プロパティ/Transformの設定、アセット操作、メニュー実行、スクリプトのステージングとコミット、再コンパイルとエラー一覧の取得 |
| **エディタ** | Scene / Gameビューのスクリーンショット、エディタメニューの実行、Playモードの操作、コンソールのログ読み取りなど |
| **動的コード** | 型付きの `uap_*` ツールでできない操作のためのC#実行（`uap_execute_code`） |
| **シーンビューのマーカー** | Sceneビューに番号付きの3Dマーカーを置く（表示のみで、シーンは変更しません） |
| **Web取得** | エージェントがURLの中身を取得する `uap_web_fetch` |

::: info Proが必要なモジュール
プレハブ、アニメーション、UI操作、アバター計測、メッシュ生成などのモジュールは、別売の拡張パッケージが必要です。詳しくは[Agent Panel Pro](./pro)を参照してください。
:::

### 使い方のポイント

- **動かして確かめる**: 「直したら実際に動かして確認して」と頼むと、エージェントがPlayモードを開始し、ゲームが出したログを読み、終わったら停止します
- **Undo**: 1ターン分のUnity操作は、Ctrl+Z 1回でまとめて元に戻せます
- **取り消せない操作**（アセット削除など）は、エージェントが `confirm:true` を付けるまで実行されず、影響範囲だけが返ります。実行前に会話で内容を確認してください
- **時間のかかる操作**はジョブになり、エージェントが `uap_job_status` で後から結果を取得します
- **ツール一覧のモード**: 設定の「ツール一覧のモード」で、フル / コンパクト（自動）を選べます。コンパクトでは、コア以外のツールは `uap_tools` / `uap_call` 経由で使います

### スクリプト検証ゲート

設定の「ステージング済みスクリプトを要求（検証ゲート）」がオンのとき、エージェントが書くC#はまず一時フォルダに置かれ、コンパイルが通ったものだけが `Assets/` に入ります。壊れたコードでドメインリロードが起きることはなく、コンパイルエラーはエージェントに返って自己修正に使われます。

::: info 対応OS
この機能はWindows向けです。
:::

## Sceneビューのマーカー・ピン・スケッチ

エージェントに「ここ」を伝える道具が3つあります。

| 道具 | 置く人 | 内容 |
|-----|-----|------|
| **マーカー** | エージェント | Sceneビューに番号付きのマーカー（球・矢印・ワイヤ箱・折れ線・ラベルなど）を置く。表示だけでシーンには保存されません |
| **ピン** | あなた | Sceneビューをクリックして置く。ワールド座標などの情報が、次の送信でエージェントに渡ります |
| **スケッチ** | あなた | Sceneビューをドラッグして線を描く。コンテキストバーにチップとして出ます |

ピンとスケッチは、Sceneビュー右下の **Agent Tools** ツールバー、またはコンテキストバーから使います。ツールバーには、ピン / 平面に描く / 表面に描くの3つのモードトグルと、右端の「表示」トグルがあります。「表示」トグルは、エージェントの表示物（マーカー・ピン・スケッチ）を消さずに隠します。

| 場面 | キー | 動作 |
|-----|-----|------|
| ピン配置中 | 左クリック / Shift+クリック / Esc | 配置 / 連続配置 / 中止 |
| スケッチ中 | 左ドラッグ / Shift+ドラッグ / 1〜5 / N / Esc | 描く / 直線・正方形 / 形 / 最新に名前 / 破棄、もう一度で終了 |
| 折れ線スケッチ中 | クリック / 最初の点をクリック / Enter / Backspace | 点を足す / 閉じる / 確定 / 1点戻す |
| 平面スケッチ中 | Ctrl+ホイール, `[` `]` / F / X, Y, Z / C | 深度 / 面に合わせる / 軸平面 / カメラ正対 |

## 再コンパイル・Playモードとの共存

- スクリプトを変更するとドメインリロードが起きますが、パネルは直前にCLIプロセスを終了してセッションIDを保存し、リロード後に同じセッションへ自動で再接続します。エディタを再起動しても、前回のセッションが復元されます
- ターンの途中でリロードが起きた場合は、「直前のターンはスクリプトの再読み込みにより中断されました。」のバナーが出ます。「続行」を押すと、エージェントが続きを実行します
- 中断が頻繁に起きる場合は、設定の **Unity連携** → **Unity操作(UapOps)** で「中断後に自動継続する」をオンにすると、パネルが自動で「続行」を送ります
- エージェントがC#を書いた後、コンパイル完了を待って作業を続けさせたい場合は「コンパイル後に自動継続する」を使います。書く → コンパイル → エラーを直す、のループを無人で回せます
- Playモード中にUnity操作ツールがタイムアウトする場合は、Project Settings の Editor にある「Enter Play Mode Settings」を見直してください
- CLIプロセスが落ちると、「エージェントのプロセスが終了しました。」のバナーと再接続ボタンが出ます。3回までは自動で再接続し、4回続けて落ちると自動再接続を止めて「再接続」を待ちます

## 設定画面

ヘッダーの ⚙ で開きます。設定は5つのタブに分かれています。項目名が分からないときは、タイトル右の検索欄に語を入れると、全タブから一致する行だけが表示されます。

| タブ | 用途 |
|-----|------|
| **概要** | 現在の状態を確認する。各行の「変更」で本来の場所へ移動できます |
| **エージェント** | 権限、モデル、カスタム指示、クイックアクションなど、会話しながら変えるもの |
| **パネル** | 表示、外観（言語・フォントサイズ）、通知、コンソールエラーの無視設定 |
| **Unity連携** | Unity操作（UapOps）、拡張プロファイル、公式プラグインなど |
| **接続** | エージェントの選択・検出・サインイン、CLIの出力（stderr）、Agent Panel Proの更新 |

- **カスタム指示**: システムプロンプトに追記する定常指示を書けます（例: 「常に日本語で回答して」）
- **クイックアクション**: ラベルとプロンプトの組を登録すると、「クイック」メニューと空状態の提案に出ます
- **言語**: 設定の **パネル** → **外観** で、自動 / 日本語 / English を選べます

::: warning 危険な設定
**エージェント** → **危険な設定** にある「すべての権限確認をスキップ（危険）」は、CLI側の確認を完全に止める設定です。通常は使いません。
:::

## 拡張プロファイル

検出したサードパーティSDKの要点を、エージェントの指示に追加する仕組みです（設定の **Unity連携** → **拡張プロファイル**）。プロジェクト直下の `.uap-profiles/*.json` に置く独自のプロファイルはCoreだけで使え、「確認して承認」で全文を確認してから有効になります。SDK向けの同梱プロファイルについては[Agent Panel Pro](./pro)を参照してください。

## よくある質問・困ったときは

| 症状 | 確認すること |
|-----|------|
| 「CLI が見つかりません」と出る | 設定の **接続** → **エージェント** → 詳細設定で、実行ファイルのパスを指定する |
| 「接続中...」のまま進まない | ログイン状態を確認する。`ANTHROPIC_API_KEY` があるとそちらが優先されるので、実際の認証方式も同じ場所で確認する。CLIの出力（stderr）も見る |
| 許可カードが多すぎる | 「常に許可」のツール単位ルールを使うか、自動承認レベルを上げる |
| 日本語がまだら太字になる、□になる | 設定の **パネル** → **外観** でCJKフォントを優先する、またはUITK Font Fixを導入する |
| エラーチップを消してしまった | 設定の **パネル** → **コンソールエラー** で無視リストから解除する |
| Unity操作ツールが「メインスレッド待ちタイムアウト」になる | Editorがフォーカスを失っているか、Playモード中。Editorに戻すか、エージェントに `uap_job_status` で結果を取らせる |
| 「認証コード」欄が押せないまま | パネルを v0.60.1-beta.6 以降に更新する。更新できないときは、[導入方法](./getting-started)のターミナルでのサインインを使う |
| 「ログインが完了しませんでした。」 | コードの貼り間違いか期限切れ。「ログイン」からやり直す |
| サインインしたのにAPIキーで課金される | サインイン方式を「サブスクリプションのみ」にする |
| 「エージェントのプロセスが繰り返し終了しました。自動再接続を停止しました。」 | CLIが4回続けて落ちた状態。ターミナルで `claude` が起動できるか確認してから、「再接続」を押す |

解決しない場合は、設定の **接続** → **CLIの出力(stderr)** と再現手順を添えて、[GitHub Issues](https://github.com/c-colloid/AgentPanelForUnity/issues)に報告してください。
