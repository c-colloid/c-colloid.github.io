# 使い方

[導入方法](./getting-started)に従ってパネルを開き、ステータスバーが「待機中」になったら使い始められます。本文中の「」内は、パネルに表示される日本語UIの文言です。

## 画面の構成

パネルは上から次の順に並びます。

| 部分 | 内容 |
|-----|------|
| **ヘッダー** | セッション名、モデルピッカー、履歴、新規セッション（+）、設定（⚙） |
| **バナー** | 再接続中・中断・エラー時のみ表示 |
| **会話ログ** | メッセージ、ツールカード、許可カード |
| **コンテキストバー** | 選択オブジェクトやエラーなどのチップ |
| **入力欄** | クイック / + / 送信・停止 |
| **ステータスバー** | 状態、モデル、コンテキストの使用率、トークン |

パネル幅が狭いときは、モデルと自動承認レベルが1つのメニューにまとまります。

## チャットの基本操作

- 入力欄に依頼を書いて **Enter** で送信（**Shift+Enter** で改行）
- 日本語入力の変換確定で誤送信してしまう場合は、設定の **エージェント** → **会話** で「Ctrl+Enter で送信」をオンにします
- 応答中は送信ボタンが「停止」に変わります。クリックまたは **Esc** でターンを中断できます
- 応答中でも入力欄は使え、Enterを押すと実行中のターンにメッセージが追加送信されます
- Unityがコンパイル中のメッセージはキューに入り、コンパイル完了後に送信されます
- **クイック** ボタンから、設定で登録した定型プロンプトを挿入できます
- 応答中の `Assets/...` のパスはリンクになり、クリックするとProjectウィンドウで該当アセットが強調表示されます
- 応答のMarkdown（見出し・リスト・表・コードブロック）はそのまま表示され、コードブロックにはコピーボタンがあります

::: tip メッセージの右クリックメニュー
**選択をコピー**、**メッセージをコピー**、**選択部分について質問** が選べます。最後の項目は、選択した文章を引用として入力欄に入れ、続けて質問を書けます。
:::

### ツールカード

エージェントが使ったツール（Read / Edit / Bash / `uap_*` など）は1行のカードになります。実行中はスピナー、完了で ✓、失敗で ✗ が付き、クリックで入力と結果を確認できます。ツールが返した画像（エディタのスクリーンショットなど）は、カードの見出し直下にサムネイル表示されます。

Claudeがサブエージェントを起動すると、入れ子のサブエージェントカードに進捗と内部のツール呼び出しが表示されます。

### スラッシュコマンドとコンテキスト圧縮

- 入力欄の先頭で `/` を打つと、CLIが提供するコマンドの候補が開きます。**↑↓** で選択、**Tab** で補完、**Enter** で送信、**Esc** で閉じます
- `/compact` を送ると、CLIがここまでの会話を要約します。会話ログに圧縮を示すノートが入ります
- コンテキストの残りが少なくなるとメーターが警告色になります。長い作業では、区切りのよいところで `/compact` を送るとよいです
- `/clear` は新規セッションと同じ動作になります

## Unityのコンテキストを渡す

コンテキストバーには、いまエージェントに渡せる情報がチップとして並びます。

| チップ | 出所 | 動作 |
|-----|-----|------|
| 選択オブジェクト | Hierarchy / Projectで選択中のもの | 自動で表示。クリックで送信対象に含める/外す |
| コンソールエラー | Consoleのエラー | 自動で表示。クリックで「修正して」の依頼につなげられる |
| ドロップしたアセット/オブジェクト | Project / Hierarchyからパネルへドラッグ&ドロップ | 添付チップとして会話に含まれる |
| 画像 | 入力欄横の **+** メニュー | 画像ファイル、Sceneビュー、Gameビュー、クリップボードの画像などを添付 |

- チップと添付画像は、次に送る通常メッセージに含まれて消費されます。スラッシュコマンドでは消費されず、次のメッセージに持ち越されます
- PNG / JPEGのファイルをパネルへドロップしても添付できます
- コンソールエラーのチップを × で消すと、そのエラーは無視リストに入ります。設定の **パネル** → **コンソールエラー** で解除できます

## 許可カード

ファイル編集・シェル実行・Unity操作など、副作用のあるツールをエージェントが使う前に、会話ログの末尾に許可カードが出ます。編集内容の差分やコマンドの内容も表示されます。

![許可カード](/images/agentpanel/permission-card.png)

| ボタン | 動作 |
|-----|------|
| **許可 (Y)** | この1回だけ許可 |
| **常に許可 ▾** | 範囲を選んで、このセッション中は確認なしにする |
| **拒否 (N)** | 拒否する。拒否の前に入力欄へ代替案を書くと、エージェントに伝わります |

カードにフォーカスがある間は、**Y** / **N** キーでも回答できます。

### 自動承認レベル

毎回確認する代わりに、ある範囲までを自動で許可できます。ヘッダー、または設定の **エージェント** → **会話** の「自動承認レベル」で選びます。

| レベル | 自動で許可される範囲 |
|-----|------|
| **毎回確認する**（既定） | なし。すべてカードで確認 |
| **読み取りのみ自動** | 読み取り系のツール（ファイル読み取り、検索、Unityのinspect系） |
| **元に戻せる操作まで自動** | 上記 + Undoで戻せるUnity操作 |
| **Unity操作は全部自動** | 上記 + すべての `uap_*` Unity操作。切り替え時に確認ダイアログが出ます |
| **全ツール自動（Bash・編集・MCP）** | Bash、ファイル編集、他のMCPサーバまで全部。エージェントからの質問だけは待ちます。切り替え時に確認が出ます |

::: warning 自動承認の範囲
レベルを上げるほど、確認なしで実行される操作が増えます。内容を把握したうえで選んでください。どのレベルでも、スクリプト検証ゲートによる自動拒否と、取り消せない操作の `confirm` ゲートは先に働きます。
:::

### 質問カード

エージェントが方針を確認したいときは、選択肢つきの質問カードが出ます。選択肢をクリックして「送信」します。「その他...」を選ぶと自由回答欄が開き、「スキップ」で回答せずに続行できます。

## セッションと履歴

- **新規セッション**: ヘッダーの **+**。現在のセッションは履歴に残ります（`/clear` でも同じ）
- **履歴**: ヘッダーの「履歴」を押すと、このプロジェクトのセッション一覧が開きます。検索、並べ替え（日付 / シーン / プロジェクト / カスタムグループ）、ピン留め、名前の変更、アーカイブ、削除ができます
- 行を選んで「切り替え」を押すと、そのセッションが復元され、会話ログが再表示されます
- セッション名は、既定では会話の先頭から自動で付きます

## モデルの選択

- **現在のセッション**: ヘッダーのモデルピッカーで、接続後にCLIから取得したモデル一覧から選びます。切り替えは即時で、結果は会話ログのシステムノートで確認できます
- **新規セッションの既定**: 設定の **エージェント** → **モデル** の「デフォルトモデル」
- **サブエージェント**: 同じ場所の「サブエージェントのコスト方針」で、「おまかせ（推奨）」か「コスト重視: 単純作業は Haiku」を選べます。新しいセッションから有効です

使えるモデルは、CLI・認証方式・アカウントによって異なります。

## キーボードショートカット

| 場面 | キー | 動作 |
|-----|-----|------|
| 入力欄 | Enter | 送信（設定でCtrl+Enterに変更可） |
| 入力欄 | Shift+Enter | 改行 |
| 入力欄 | Esc | 実行中のターンを停止 |
| 会話ログ（文章を選択中） | Ctrl+C / Cmd+C | 選択した文章をコピー |
| スラッシュ候補 | ↑ / ↓ / Tab / Enter / Esc | 選択 / 補完 / 送信 / 閉じる |
| 許可カード（フォーカス時） | Y / N | 許可 / 拒否 |
| Unity | Ctrl+Z | 直前のターンのUnity操作をまとめて取り消し |

Sceneビューでのピン・スケッチ操作のキーは[詳細設定](./details)を参照してください。
